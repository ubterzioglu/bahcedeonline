# Plan: Referans Frontend'inin Mevcut Projeye Alınması

## Hedef

`referans/` altındaki projenin frontend'ini mevcut projeye aktarmak, i18n sistemini korumak, backend'e dokunmamak.

## Yaklasim

Referans projesinin frontend dosyalarini **kaynak** olarak al, uzerine mevcut projenin i18n sistemini ekle.

## 2. Referanstan Alinip i18n Eklenecek Dosyalar

Her dosya icin islem:

1. Referans versiyonunu al
2. Route path'lerini `/$locale/...` formatina cevir
3. Hardcoded Turkce string'leri `dictionary.*` ile degistir
4. Link'leri `locale`-aware hale getir

## 4. Her Dosya Icin i18n Pattern'i

Her route dosyasinda ayni transformasyon uygulanacak:

```tsx
// Once (referans)
import { createFileRoute } from '@tanstack/react-router'
export const Route = createFileRoute('/menu')(...)
const label = "Turkce string"

// After (hedef)
import { createFileRoute } from '@tanstack/react-router'
import { useI18n } from '@/lib/i18n'
export const Route = createFileRoute('/$locale/menu')(...)
const { locale, dictionary } = useI18n()
const label = dictionary.menuPage.xxx

// Link'ler
<Link to="/menu">        →  <Link to="/$locale/menu" params={{ locale }}>
navigate({ to: '/admin' }) →  navigate({ to: '/$locale/admin', params: { locale } })
```
